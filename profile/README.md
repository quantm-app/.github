## Quantm

A free, open-source desktop app for SoundCloud (unofficial), for Windows, macOS and Linux.

- 25+ themes, including overhauls like **Listening Room**, **Pocket Quantm** and **Terminal Multiplexer**
- DJ-style transitions, cue points, equalizer, sleep timer and listening stats
- Offline downloads for tracks the artist allows, local playlists, Discord status
- No ads, and it updates itself
